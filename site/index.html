FAQ / 常见问题

你可能
还想知道。

真的能提取高清原图吗？+

对支持的平台会优先还原。比如 Amazon 的 ._AC_SL300_.jpg 会变成原始尺寸文件，淘宝/1688 的 .jpg_400x400.jpg 会去掉缩放后缀。个别站点使用签名 URL 或服务端裁切，无法绕过，此时会保留页面上的最大版本。

为什么安装时提示「开发者模式扩展」？+

v1.1.0 以本地安装包发布，尚未上架 Chrome Web Store 或 Edge Add-ons。开启开发者模式、加载解压后的文件夹是 Chrome/Edge 官方支持的安装方式，不影响扩展能力。

图片会被上传到你们的服务器吗？+

不会。图仓没有后端服务器，也没有统计 SDK。扩展在本地读取页面图片地址，从图片原站点拉取文件，在浏览器里生成 ZIP。你的浏览记录、商品页和图片都不会发给我们。

为什么有个别图片打包失败？+

部分 CDN 会检查来源页或登录状态，阻止第三方直接拉取。ZIP 会跳过这些图片并保留其余结果；需要那一张时，可以用「逐张下载」，让浏览器带上当前页面的登录态去保存。

支持视频和详情页长图吗？+

目前专注商品图片。详情页里以 img 或背景图出现的长图会被抓取；视频暂不处理，但可以提取视频封面图。

会上架应用商店吗？+

这是 v1.1.0 的第一个公开版本，正在准备商店审核。当前版本功能完整，可以先用本地包；后续商店版会保持同样的本地处理方式。
